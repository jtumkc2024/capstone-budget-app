1. Create a New Project
Route: POST /api/project/create

POST http://localhost:3000/api/project/create
Content-Type: application/json
Body:
{
  "user_id": 1,
  "project_title": "New Project",
  "project_description": "Detailed description of the project",
  "renewable": true,
  "priority": "High",
  "deadline": "2024-12-31"
}

Response:json

{
  "message": "Project created successfully",
  "projectId": 1
}


2. Fetch All Projects
Route: GET /api/project/all

GET http://localhost:3000/api/project/all

Response:json

[
  {
    "project_id": 1,
    "user_id": 1,
    "project_title": "New Project",
    "project_description": "Detailed description of the project",
    "renewable": true,
    "priority": "High",
    "deadline": "2024-12-31"
  }
]


3. Fetch Projects by User ID
Route: GET /api/project/user/:user_id

GET http://localhost:3000/api/project/user/1

Response:json

[
  {
    "project_id": 1,
    "user_id": 1,
    "project_title": "New Project",
    "project_description": "Detailed description of the project",
    "renewable": true,
    "priority": "High",
    "deadline": "2024-12-31"
  }
]


4. Update a Project
Route: PUT /api/project/update/:project_id

PUT http://localhost:3000/api/project/update/1
Content-Type: application/json
Body:
{
  "project_title": "Updated Project",
  "renewable": false
}

Response:json

{
  "message": "Project updated successfully"
}

5. Delete a Project
Route: DELETE /api/project/delete/:project_id

DELETE http://localhost:3000/api/project/delete/1

Response:json

{
  "message": "Project deleted successfully"
}
